# LegalEase - Pre-requisites

## 1. FastAPI Framework Knowledge

Basic knowledge of the FastAPI framework is required for developing the backend API of LegalEase.

## 2. Google Gemini API Familiarity

Familiarity with the Google Generative AI API is required to integrate the Gemini model for legal document generation.

## 3. Streamlit for Frontend

Basic knowledge of Streamlit is required to develop the user interface for entering document details, previewing generated content, and downloading documents.

## 4. Python Programming Proficiency

Python programming knowledge is required to develop and integrate the different components of the LegalEase application.

## 5. Environment Setup

The project requires the following Python packages:

- fastapi
- uvicorn
- streamlit
- python-docx
- fpdf
- Pillow
- requests
- google-generativeai
- python-dotenv
