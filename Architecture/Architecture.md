# LegalEase - Application Architecture

## Overview

LegalEase is an AI-powered legal document generation application.

## Main Components

- Streamlit Frontend
- FastAPI Backend
- Google Gemini AI
- Document Generation Modules
- Document Export

## Application Flow

User
↓
Streamlit Frontend
↓
FastAPI Backend
↓
Gemini AI
↓
Generated Legal Document
↓
Preview and Export
