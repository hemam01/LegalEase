# LegalEase - Development Environment Setup

## 1. Programming Language

Python is used for developing the LegalEase application.

## 2. Backend Framework

FastAPI is used to develop the backend API.

Uvicorn is used to run the FastAPI application locally.

## 3. Frontend Framework

Streamlit is used to create the user interface.

## 4. Generative AI

Google Gemini is used for Generative AI-based legal document generation.

## 5. Required Libraries

The project requires the following packages:

- fastapi
- uvicorn
- streamlit
- python-docx
- fpdf
- Pillow
- requests
- google-generativeai
- python-dotenv

## 6. Environment Variables

The Gemini API key should be stored in a `.env` file.

The API key must not be directly written inside the source code or uploaded to GitHub.

## 7. Project Environment

A Python virtual environment should be used to install and manage the project dependencies.
